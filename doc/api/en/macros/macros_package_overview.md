# actors.macros

## Function Description

This package provides users with macros for declaring actors, actor interfaces, and receiver functions. It supports both local and distributed actor programming models with comprehensive configuration options.

## API List

### Macros

|              Macros          |           Function           |
| --------------------------- | ------------------------ |
| [@Actor](./macros_package_api/macros_package_macros.md#actor-macro)     | Declare an actor class.   |
| [@ActorInterface](./macros_package_api/macros_package_macros.md#actorinterface-macro)     | Declare an actor interface for both local and distributed use. |
| [@Receiver](./macros_package_api/macros_package_macros.md#receiver-macro)     | Declare a receiver function within an actor or actor interface. |
